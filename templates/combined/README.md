# 组合项目模板

用于共同开发和发布数据包、资源包与地图。复制到 `projects/<项目名>/` 后修改
项目 ID、命名空间、版本说明和各组件元数据。

- `datapack/`：包含独立 Beet 配置的数据包源码。
- `resourcepack/`：包含 `pack.mcmeta` 和 `assets/` 的资源包。
- `world/`：用于制作发行版的源地图，当前仅占位。
- `overrides/`：可选的额外分发文件，当前未加入任何目标。
- `docs/`、`tests/`：项目说明与联合验证。

`project.json` 提供 `datapack`、`resourcepack`、`map` 三个目标声明。
`map` 选择全部三个组件；组件列表不表示打包顺序。
删除不需要的组件时，也应更新对应目标。

数据包可在 `datapack/` 中运行 `beet build`。统一构建器尚未实现，
地图目标的包安装、资源包嵌入和发行版打包也尚未实现。
不要把游戏运行和测试的世界副本写回源地图；本地副本使用 `.local/`。
