# 网页项目模板

复制到 `projects/<项目名>/`，修改 `project.json` 中的项目 ID，并填写用途与运行说明。

- `web/`：网页组件的源码目录，提供一个无外部依赖的 HTML 起始页面。
- `docs/`、`tests/`：项目说明和测试。
- `project.json`：声明 `web` 组件和同名目标；统一构建器尚未实现。

静态页面可以直接用浏览器打开。也可以从复制后的项目根目录运行本地预览：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

然后打开 <http://127.0.0.1:8000/>。该命令只用于本地静态预览。

采用前端框架后，可用框架源码替换 `web/` 的内容，在该组件内保存依赖清单、
锁文件、框架配置和构建命令，并同步更新项目说明。模板不预设 Node.js 版本或包管理器。

给现有地图或包项目增加配套网页时，将网页源码放入该项目的 `web/`，并在其
`project.json` 中增加 `web` 组件和网页目标。原有地图或包目标可以保持各自的组件选择。
