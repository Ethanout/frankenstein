# 术语表

每个概念只用一个名称，括号内是旧文档中出现过的别名。

## 结构

| 术语 | 含义 | 例 |
| --- | --- | --- |
| 模块 | 用 Minecraft 命名空间表示的命名单位 | `demo` |
| 主包 | 项目的主体，命名空间用项目名 | `fn` |
| 附属包 | 可选装的附属功能，命名空间为 `<项目>.<包名>` | `fn.unbake` |
| 前置类工具包 | 供其他包调用的库，本身不提供玩法 | Bookshelf |
| 角色（特殊类） | storage ID 冒号后的部分，表示数据用途；`io`、`temp`、`data`、`ins`、`stat` 内置，其他在 `frank.txt` 中用 `special` 声明 | `fn:io`、`fn:data` |
| 类（字段） | 一组数据命名和格式的约定，数据可放在 storage、记分板、实体或方块中 | `player` |
| 属性 | 对象的一部分数据 | `pos.x` |
| 全名 | 一项数据的 `<module>.<class>.<项>`，放到任何位置都保留 | `demo.player.level` |
| 继承类 | 更具体的类型，父类在前 | `character.knight` |
| 方法 | 属于某个类的函数 | `demo:player/update` |
| 接口 | 调用者与函数约定的调用方式、输入、输出；作为入口的方法叫接口方法（接口函数） | `demo:character/hurt` |
| 普通接口 | 只管算法本身的接口，不做输入校验，性能好、调用步骤多 | `fn:store/modify` |
| 封装接口 | 校验输入、补默认值后调用普通接口的干净入口 | `#fn:store/modify` |
| 中间过程（子过程） | 只给一个方法用的辅助函数 | `demo:player/update/check_state` |
| 私有方法 | 类及其继承类内部共享的方法 | `demo:player/__validate` |
| 自动方法（自动入口） | 由游戏机制、函数标签或手动入口调用的方法 | `__tick__` |
| 别名 | 只转发另一方法、行为等价的方法 | `__tick__` → `tick` |

## 变量

| 术语 | 含义 | 例 |
| --- | --- | --- |
| 接口变量（接口值） | 按接口约定读写的变量，当前 tick 有效 | `pos.x` |
| 类内变量 | 只供本类方法使用的变量，当前 tick 有效 | `pos.__a` |
| 跨 tick 变量（长期变量） | 跨 tick 保留的接口变量 | `pos.__count__` |
| 临时变量 | 方法内使用，调用其他方法后失效 | `#a`、`#temp_a` |
| 强制临时变量 | 调用任意函数后失效 | `##a` |
| 常量 | 放在 `<module>` 记分项上、假名即数值的只读分数 | `16`、`#16` |
| 失效 | 不能再依赖旧值；数据本身不会被清除 | — |
| 变量栈 | 用 `<module>:ins <class>` 列表为每次调用分别保存数据 | `demo:ins item[0]` |
| 回调数据 | 只在回调运行期间有效的数据，项目规范和接口数据一样放在 `<module>:io <class>` | `storage fn:io ray` |
| 世界实体 | 用固定 UUID、常驻常加载区块的工作实体 | `c0ffee-0-0-0-1` |
| 后端／前端 | 后端是玩家看不到的状态（storage、记分板、世界实体等）；前端是玩家看得到、碰得到的方块、实体和物品 | — |

## 文档

| 术语 | 含义 | 例 |
| --- | --- | --- |
| 头文档 | 文件开头以 `#> ` 起始的连续注释 | `#> demo:a/b` |
| 标签（文档字段） | 头文档中 `@名称` 及其下方内容 | `@input` |
| 副作用 | 输出以外的状态变化 | 移除某个 tag |
| 通用协作规范 | 包与包之间的约定，即 `core.md` | — |
| 项目规范（frank 规范） | 本项目的包内写法，即 `style/` 下的规则 | — |
| 检查等级 | 工具报告的严格程度，1 宽松、2 正常、3 严格 | — |
| frank 表达式 | 头文档使用的伪代码写法，可选做形式化检查 | `score(@s demo.hp)` |
| 数据位置 | frank 中表示数据所在之处 | `storage(demo:io player.level)` |
| 逻辑记法 | 规范正文中描述位置的简写，不可直接运行 | `score player.level demo` |

“标签”指头文档的 `@input` 等；实体的 tag 写作“实体 tag”，两者不混用。
