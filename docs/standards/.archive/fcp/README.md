# FCP — Frankenstein 约定提案

FCP（Frankenstein Convention Proposals）是一组供 Frankenstein 项目及自愿采用的项目使用的开发约定提案，采用 Python PEP 风格的编号、文档头和提案状态。

当前提案主要讨论 MCFunction 与 Beet/Bolt 项目的命名、存储和接口约定，游戏版本基线为 Minecraft Java 1.15+。后续可按主题加入构建器、网页等开发约定。

- [核心概念](../core-concepts.md)：查阅各篇规范共用的术语。
- [FCP 0：提案索引](fcp-0000-index.md)：查看全部提案。
- [FCP 1：提案流程与规范用语](fcp-0001-process.md)：了解类型、状态和“必须／应该／可以”。
- [frank 文档表达式](../frank/quickstart.md)：统一、简洁的伪代码写法，以及可选的形式化检查。
- [FCP 9：frank 在函数文档中的使用](fcp-0009-frank-expressions.md)：语言与 MCFunction 头文档的衔接。
- [提案模板](proposal-template.md)：起草新提案。

当前规范提案均为 Draft。项目可按 FCP 1 记录自己的采用范围。
