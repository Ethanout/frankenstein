# FCP N — 提案标题

```text
FCP: N
Title: 提案标题
Author: 待填写
Status: Draft
Type: Standards Track
Created: DD-Mmm-YYYY
Minecraft-Version: 1.15+
Requires: 1
```

文档头填写说明：

- `FCP`：分配后的编号，文件名补齐四位数字。
- `Type`：Standards Track、Informational 或 Process。
- `Minecraft-Version`：游戏版本条件；与游戏版本无关时省略。
- `Requires`：依赖的提案编号；无依赖时省略。
- `Replaces`、`Superseded-By`：发生替代关系时添加。

## 摘要

用一段话说明提案解决什么问题、提出什么方案。

## 动机

说明现有做法遇到的具体问题，以及为什么需要统一约定。

## 规范

说明适用范围、术语和规则。围绕实际阅读顺序组织段落，需要时配合小表格和代码示例。

条款形式：

**FCP-NNNN-R01 · 应该：** 写出适用条件和具体行为。

规则等级见 [FCP 1](fcp-0001-process.md)。

## 设计理由

解释关键选择，以及采用该方案的收益和代价。

## 未决问题

有尚待决定的具体问题时，在这里简要列出；确定后直接更新规范正文。本节可省略。

## 参考资料

链接到相关提案、来源或外部文档。
